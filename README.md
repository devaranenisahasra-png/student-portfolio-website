# Student Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Home and About sections
- Skills cards
- Project cards
- Contact form with basic client-side validation
- Mobile navigation menu
- Responsive layout for phones and laptops
- Smooth scrolling and hover effects

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)

## How to run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Customize before submission
- Confirm the name and contact details in `index.html`.
- Replace sample project descriptions with your own completed work.
- Add your actual GitHub and LinkedIn profile URLs.
- Take screenshots of the website running in your browser.

## Important note
The contact form is a front-end demonstration only. It validates the fields but does not send or save messages.

## Project objective
To learn how HTML structures a web page, CSS styles and arranges its layout, and JavaScript adds interaction.
